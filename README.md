# BLOG – טופ שבמתמחים

האתר: https://top-shebamitmachim.github.io/

תוכנות, תוספים לכרום וסקריפטים חינמיים בקוד פתוח – עם מדריכי התקנה בעברית.

## מבנה
- `index.html` – כל האתר בדף אחד: הפרויקטים, חיפוש וסינון לפי סוג. לחיצה על פרויקט פותחת חלונית עם מדריך התקנה והורדה, ולכל פרויקט יש קישור ישיר (למשל `/#top-gif`)
- `404.html` – מעביר קישורים ישנים (`/BLOG/...`, `guide.html`, `MIT.html` וכו') למקום החדש
- `main.css` – כל העיצוב (מצב כהה ובהיר מוגדרים כמשתנים בראש הקובץ)
- `theme.css` – כפתור מצב בהיר/כהה וחלונית "צור עמנו קשר"
- `site.js` – מצב בהיר/כהה, `contact-widget.js` – חלונית יצירת קשר, `ui.js` – חיפוש, לשוניות, כפתורי העתקה וחלוניות הפרויקטים
- `img/` – לוגו, אייקונים, תמונות שער וצילומי מסך למדריכים
