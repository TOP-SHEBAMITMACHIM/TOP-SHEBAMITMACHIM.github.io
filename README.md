# BLOG – טופ שבמתמחים

האתר: https://top-shebamitmachim.github.io/

תוכנות, תוספים לכרום וסקריפטים חינמיים בקוד פתוח – עם מדריכי התקנה בעברית.

## מבנה
- `index.html` – דף הבית: כל הפרויקטים, חיפוש וסינון לפי סוג
- דף לכל פרויקט: `top-gif.html`, `chatsapp.html`, `guide.html` (מעצב צ'אט), `MIT.html` (תגובה מהירה), `emogi.html`, `link-to-new-guide.html` (מנקה כוכביות), `convertop.html`, `adshield.html`
- `main.css` – כל העיצוב (מצב כהה ובהיר מוגדרים כמשתנים בראש הקובץ)
- `theme.css` – כפתור מצב בהיר/כהה וחלונית "צור עמנו קשר"
- `site.js` – מצב בהיר/כהה, `contact-widget.js` – חלונית יצירת קשר, `ui.js` – חיפוש, לשוניות וכפתורי העתקה
- `img/` – לוגו, אייקונים ותמונות שער מכווצות
